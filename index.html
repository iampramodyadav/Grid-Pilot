Why GridPilot

Built for the file you actually work with

Not a spreadsheet. Not a text editor. The tool that lives between them — purpose-built for structured data files.

⚡

Opens in <1 second

A 200k-row CSV opens instantly. Excel takes 8–12 seconds for the same file and sometimes crashes. GridPilot never locks the file on disk.

📂

Multi-file sessions

Open your load case file, sensor catalogue, and reference table simultaneously. Each tab is fully independent — separate undo history, separator, and formatting rules.

🔍

Filter that actually edits

Filter to 14 matching rows and edit them directly. Changes write back to the correct rows in the full dataset. Clear the filter — every edit is there.

🎯

Knows your formats

Auto-detects comma, tab, semicolon, pipe, space, and #label custom formats used in FEA and MDT parameter files. No manual separator selection on every open.

🔌

Python plugins in 10 lines

Write a Python function, save it, click Reload. It appears in the Plugins menu instantly. Full pandas access — unit conversions, custom exports, validation, batch rename.

🎥

Notepad++ style macros

Record any sequence of actions — navigation, typed values, paste, operations. Run it 50 times to process 50 rows. Each pass starts where the previous ended.

645 Functions

The complete formula engine — SUM, VLOOKUP, INDEX/MATCH, COUNTIF, STDEV, and 640 more. Type = in any cell. Yellow = valid, red = error.

  • Mixed absolute/relative references ($A$1 syntax)

Notepad++ Macros

Records every action — not just menu clicks. Arrow keys, typed values, paste, delete. Navigation is relative, so running the macro 100 times processes 100 rows.

  • F9 to start/stop · F10 to quick-play
  • Relative cursor: each repeat starts where previous ended
  • Captures formulas as formulas, not evaluated values
  • JSON step format — editable by hand
  • Run N times dialog with live step preview
1move_rel dr=1, dc=0

5op clean_whitespace [2 Δ]

2D & 3D Charts

Full matplotlib embedded in the app. Configure columns on the left, see the chart on the right. Overlay multiple sheets on the same axes.

  • 2D: Scatter, Line, Bar, Histogram, Heatmap, Pie, Polar, Box/Violin
  • 3D: Scatter+colour, Surface, Plane Fit (Z=aX+bY+c), Line, Bar
  • Overlay any two open sheets for comparison
  • Save PNG / PDF / SVG / JPEG
  • Full navigation toolbar — pan, zoom, reset

Python Plugins

Write a decorated Python function. Save the file. Click Reload Plugins. It appears in the menu. No restart. Full pandas and numpy access.

  • Return a DataFrame → replaces the sheet (goes to undo stack)
  • Return None → side-effects only (export, notify)
  • Access any open tab via app.workbook_sheets
  • Open dialogs, write files, call external APIs
  • Works with the macro recorder — @recordable decorator
