1. Installation

Download GridPilot

Windows installer — no Python installation required

⬇ GridPilot-Setup.exe  ·  Windows 10/11 ⎇ Source on GitHub

Version 1.0.0  ·  ~45 MB  ·  SHA-256 checksum available on GitHub Releases

Run from source

Requires Python 3.10 or later.

# Clone the repository
git clone https://github.com/yourusername/gridpilot.git
cd gridpilot

# Install dependencies
pip install -r requirements.txt

# Run
python main_app.py
