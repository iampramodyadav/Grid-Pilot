v1.0.0
2025 — Initial Release
Major release Feature

First public release of GridPilot. Built from the ground up for engineers working with simulation data, FEA parameter files, sensor catalogues, and MDT load case tables. 30-day trial included — no account required.

Core Editor

  • Multi-file session — open unlimited files simultaneously, each tab fully independent
  • Auto-detects separators: comma, tab, semicolon, pipe, space, #label format
  • Per-tab undo/redo stack — each tab has its own complete history
  • Silent save (Ctrl+S) — no popup, no confirmation dialog
  • Save All (Ctrl+Shift+S) — saves every modified tab in one pass
  • Find & Replace — current sheet (Ctrl+H) and all sheets (Ctrl+Shift+H)
  • Copy full path and Open containing folder (Notepad++ style)

Autofill — Excel Style

  • Drag fill handle — green square at selection corner, drag in any direction
  • Pattern detection: numbers (any step), month names, day names, prefixed IDs (MB_001→MB_002)
  • Formula fill — relative references adjust correctly (=A1+B1 → =A2+B2)
  • Absolute references ($A$1) respected and not adjusted
  • Keyboard autofill (Ctrl+R) — fills empty cells from surrounding seeds

Formula Engine

  • 645 functions — math, statistics, logic, lookup, text, date
  • Formula bar with yellow (valid) / red (error) cell highlighting
  • Searchable formula browser with usage templates
  • Auto-calculate mode (default) and manual recalculate

Row Filter Bar

  • Live filter (Ctrl+F) — plain text, wildcard (*), and full regex modes
  • Write-back editing — edits made while filtered write to correct original rows
  • Per-tab filter memory — each tab remembers its filter state on switch

Conditional Formatting

  • 14 condition types: greater/less than, equals, contains, between, top N, above average, duplicate, empty, regex
  • Colour entire row option — live match count per rule
  • Rules applied top-down, reorder with ↑↓ — preview mode

Pivot Table Builder

  • Drag-and-drop field assignment: Rows, Columns, Values, Filters
  • 9 aggregation functions: Sum, Mean, Count, Count Unique, Min, Max, Median, Std Dev, First/Last
  • Export as CSV or Excel, or send result to new tab

Sheet Compare (Diff)

  • Key-column alignment (rows may be reordered) or positional alignment
  • Colour coded: yellow = changed, green = added, red = removed
  • Navigate between differences, export coloured Excel

Macro Recorder

  • Notepad++ style — records navigation, typed values, paste, delete, named operations
  • Relative cursor positioning — each repeat starts where previous ended
  • F9 start/stop · F10 quick-play · Run N times dialog with step preview
  • JSON step format — editable by hand in the built-in macro editor

Plot Builder

  • 2D: Scatter (+colour col), Line, Histogram, Bar, Heatmap, Pie, Polar, Box/Violin
  • 3D: Scatter (+colour), Line, Surface (scipy interpolation), Plane Fit, Plane Only, 3D Bar
  • Overlay multiple sheets on same axes — save PNG/PDF/SVG/JPEG

Plugin System

  • Write Python functions with @register("Label") — appear in Plugins menu instantly
  • Full pandas / numpy access — return DataFrame to replace sheet, or None for side-effects
  • @recordable decorator for macro-aware plugins

More Features

  • Command palette (Ctrl+P) — fuzzy search across all actions and plugins
  • Split view (Ctrl+Shift+V) — two sheets side by side, live sync
  • Column Inspector — stats dashboard, one-line transform expressions, validation rules
  • Colour bookmarks — right-click any selection to apply highlight colours
  • Raw text viewer (Ctrl+T) — see the file exactly as it will be saved, column-colour highlighted
  • Drag-and-drop file open (requires tkinterdnd2)
  • 20+ ttkbootstrap themes with live preview picker
  • Splash screen on startup with progress bar
  • Arcade games — Snake, Tetris, Tic-Tac-Toe, Game of Life (in spreadsheet cells)
  • Offline licence system — Single, Team, Enterprise editions
v0.9.0 — Beta
2025 — Private Beta
Feature Fix

Internal beta tested with wind energy engineering teams. Major architectural work — mixin system established, all features integrated.

Added

  • Mixin architecture — each feature is a self-contained mixin class
  • UndoMixin — unified per-tab undo/redo snapshot stack
  • FilterMixin v2 — index-map write-back so edits persist through filter/clear cycle
  • CFMixin v2 — incremental diff rendering (only changed cells repainted)
  • MacroMixin — df-diff architecture replaces method-name recording
  • PlotMixin — robust column detection handles CSV object-dtype columns

Fixed

  • Preferences dialog — tb.Combobox → ttk.Combobox to prevent ttkbootstrap Publisher crash on dark mode toggle
  • Pivot window — tb.Frame replaced with tk.Frame to fix -bg option error
  • Dialog pack order — buttons and options packed side="bottom" before body so they never disappear in compiled exe
  • Tetris — _clear_lines now deletes rows in reverse index order, fixing freeze when 2+ rows cleared simultaneously
  • Tic-Tac-Toe — replaced extra_bindings(cell_select) with MT.bind(ButtonRelease-1) so clicks register correctly
  • Formula engine — guard against None sheet reference in _on_sheet_change

Improved

  • Macro recorder — navigation now recorded as relative move_rel(dr,dc) steps, not absolute positions
  • Plot mixin column detection — coerces string-typed numeric columns (handles real CSV data)
  • Arcade games — sidebar panel replaces status row in tiny cells; all game status now readable
